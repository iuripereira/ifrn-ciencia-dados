# Atividade prática - aula 06

Reproduza o exemplo prático desta aula (Exemplo — Fontes de Dados e APIs Públicas) e envie seu script ou notebook com as seguintes tarefas:

- Carregue o arquivo dados/cnes_rn_amostra.json (ou um conjunto de dados público à sua escolha, de fonte governamental) e registre a proveniência (fonte, endpoint, data da coleta, licença).
- Grave os dados em uma tabela SQLite e escreva uma consulta SQL própria (diferente da do exemplo) usando GROUP BY.
- Exporte o mesmo conjunto de dados em pelo menos dois formatos (por exemplo, CSV e Parquet) e compare o tamanho dos arquivos gerados.
- Escreva, em texto, uma checklist de verificação ética e legal (robots.txt, termos de uso, licença) que você seguiria antes de fazer scraping de um site à sua escolha.
- Opcional (pontuação extra): gere um mapa ou gráfico com os dados coletados.
- Envie o arquivo .py ou .ipynb com o código comentado. Prazo de envio: até 13/10/2026 (15 dias após esta aula).
