# Fatores relevantes para Valor Adicionado

## Atividade 07

Turma!!

Conforme decidimos em sala de aula, temos um TRABALHO PARA ENTREGAR. Façam em Grupo; o mesmo que conduzirá nosso Projeto.

Utilizando os Portais Observatório Sebrae, IpeaData e Ibge-Cidades, elaborem um texto mostrando Fatores relevantes para que um Município tenha alto Valor Adicionado no setor de INDÚSTRIA, no de Serviços, no de Administração. Para isto, realizem as ações:

- (1) Selecionem PELO MENOS UM MUNICÍPIO com alto Valor Adicionado na Indústria 
- (2) Identifiquem fatores relevantes para essa realidade
- (3) Elaborem um TEXTO, com gráficos, explicando essa realidade
- (4) Repitam os itens (1), (2) e (3) para Serviços, e finalmente para a Administração.
- (5) Apresentem CONTRIBUIÇÕES, dialogando o TEXTO produzido com UM ARTIGO sobre desenvolvimento sócioeconômico.
